# 🛍️ Velora — E-Commerce Website  

**Velora** is a **multi-page e-commerce website** created as my **final project** for the Web Development module.  
It demonstrates the use of **HTML, CSS, and JavaScript** to build a fully responsive, interactive, and modern online store.  

👉 **Live Demo on Netlify:** [https://velor.netlify.app/]  

---

## 📖 About Velora  

Velora is designed as a **fashion and lifestyle e-commerce website**.  
The goal of the project is to provide a clean, user-friendly platform where visitors can explore products, read styling and lifestyle tips, and get in touch with the brand.  

It combines **aesthetic design** with **functionality**, featuring:  
- A responsive navigation bar and layout.  
- Product catalog with **Add to Cart** functionality.  
- A blog section for **fashion and lifestyle tips**.  
- A working contact form with a **success message alert**.  
- Consistent branding across all pages.  

---

## 📂 Pages in the Project  

The Velora website includes the following pages:  

1. **Home Page (`index.html`)**  
   - Landing page with hero section and brand introduction.  
   - Features a search bar and navigation to other pages.  
   - Clean, responsive layout with images and quick links.  

2. **About Page (`about.html`)**  
   - Tells the story of Velora and its mission.  
   - Includes a founder’s bio (*Nomize*), team section, and responsive images.  
   - Highlights Velora’s values: Innovation, Integrity, Global Impact, Customer First.  

3. **Products Page (`products.html`)**  
   - Displays products in a **grid of product cards** with consistent design.  
   - Each card shows a product image, description, price, and an **Add to Cart** button.  
   - Products are categorized (e.g., Tech, Fashion, Lifestyle).  
   - Fully cohesive design across all products.  

4. **Blog Page (`blog.html`)**  
   - Showcases lifestyle and fashion-focused blog posts.  
   - Topics include:  
     - *5 Must-Have Pieces for a Capsule Wardrobe*  
     - *How to Accessorize Any Outfit*  
     - *Lifestyle Hacks for Effortless Elegance*  
   - Each post has a preview and a **Read More** button linking to the full post.  

5. **Contact Page (`contact.html`)**  
   - Contains a functional contact form.  
   - On submission, users get a **“Message sent successfully” notification**.  
   - Includes brand contact details (email, phone, location) and a Google Maps embed.

## 🚀 Deployment to Netlify  

Velora was deployed using **Netlify**, allowing the project to be accessible online.  

**Deployment steps followed:**  
1. Created a GitHub repository and committed the project files.  
2. Linked the repository to Netlify using **“New Site from Git”**.  
3. Set the branch to `main` and published directly from the repo.  
4. Netlify automatically deployed the site and updates whenever I push changes.
